# Veterinaria San Marcos - versión básica

Proyecto frontend hecho con HTML, CSS y JavaScript.

Esta versión está simplificada para que el código sea fácil de leer y explicar.
No usa frameworks, backend ni base de datos.

## Cómo abrir

Link: https://hanaeru.github.io/fullstack2-vetsanmarcos/

1. Abre la carpeta en Visual Studio Code.
2. Abre `index.html` con Live Server.

## Páginas

- `index.html`: página principal.
- `login.html`: inicio de sesión de ejemplo.
- `registro.html`: registro de ejemplo.
- `admin.html`: panel de administrador.
- `recepcion.html`: panel de recepción.
- `veterinario.html`: panel del veterinario.
- `tecnico.html`: panel del técnico.
- `cliente.html`: panel del cliente.

## Cómo probar el login

Puedes escribir cualquier correo con formato válido y una contraseña de 6 o más caracteres.
Después debes elegir un rol.

Ejemplo:

- Correo: `admin@sanmarcos.cl`
- Contraseña: `123456`
- Rol: Administrador

## Importante

El inicio de sesión y el registro son simulaciones.
Los datos del sistema se guardan en el navegador usando `localStorage` y `sessionStorage`.
No existe conexión a un servidor ni a una base de datos real.
